# Portfolio — Chinavath Raghavendra

An interactive, dark-themed personal portfolio website featuring a smooth, 60fps canvas-driven scroll animation, responsive glassmorphism UI, and modern editorial typography.

## 🚀 Features
- **Cinematic Scroll Animation**: Real-time canvas interpolation (lerp) scrubbing through high-resolution frames with automatic high-DPI scaling and dynamic watermark inpainting.
- **Modern Responsive Design**: Translucent glassmorphism cards with glowing ambient hover effects, sleek borders, and high contrast against dark atmospheric lighting.
- **Sections**:
  - **Hero**: Elevated, high-contrast typography ("CHINAVATH Raghavendra") with signature warm fiery gradient.
  - **About Me / Education**: Background in CSE (AI & ML) at Joy University through the NIAT Upskilling Program.
  - **Projects**: Voter Eligibility Checker, Calculator, ATM Management System, Student Grade Calculator.
  - **Technical Skills**: Four numbered editorial columns highlighting Programming, Web Development, Generative AI, and Creative Media.
  - **Contact**: Full-width interactive footer with direct phone, email, LinkedIn, and GitHub links.
- **Click-to-Expand Profile**: Quick profile modal with portrait framing and section tags.

## 🛠️ Tech Stack
- HTML5 / CSS3 (Glassmorphism & Flexbox/Grid)
- JavaScript (Vanilla, RequestAnimationFrame Easing)
- HTML5 Canvas API
